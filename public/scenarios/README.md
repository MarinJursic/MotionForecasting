# Real-world evidence clips

This directory contains locally bundled VP9 WebM and H.264 MP4 derivatives of licensed real traffic footage, plus JPEG posters. Attribution, source links, license terms, and transformation notes are recorded in [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).

The overlays are curated demonstration annotations authored for this repository. They are not synthetic vehicles, source-provided benchmark labels, physical coordinates, or automatic collision determinations.
